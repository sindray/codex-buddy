# Codex Buddy 发布准备

当前桌面版：0.3.0，macOS 13+，Apple Silicon / Intel。支持 USB 与 BLE。Windows / Linux 尚未实现。

## 首次使用

1. 设备安装支持 Codex Buddy v1 的固件（当前兼容版本 0.4.7），接通电源。
2. 下载并解压电脑助手，移入“应用程序”，双击打开。
3. 在连接引导中检查本机 Codex；自定义数据目录可手动选择。发起一个 Codex 任务确认变化。
4. 允许系统蓝牙权限，确认自己的设备。多台设备时按名称及标识后六位选择；USB 连接优先。
5. 两项检测通过后完成引导。登录启动由用户主动开启。

## 当前可交付的本地产物

- `build/Codex Buddy.app`：原生应用，无 Python 依赖。
- `build/Codex-Buddy-macOS.zip`：解压即用压缩包。
- 现在只有临时本地签名。不得将其描述成已公证、已通过商店审核或在其他电脑上完成验收的正式包。

## 正式公开分发前

- [ ] 确认 Apple Developer ID 签名证书与公证条件；签名、公证并校验最终下载包。
- [ ] 提供固定的 HTTPS 下载地址、版本说明和反馈入口。先人工下载更新即可，不强制添加自动更新服务。
- [ ] 在另一台 Mac 从下载开始测试，覆盖首次打开、蓝牙拒绝与恢复、自定义目录、首次连接和设备选择。
- [ ] 用真实 Codex 任务验证开始、工具执行、等待、完成、多个任务；记录 Codex 版本。当前读取本地记录，格式变化可能影响识别。
- [ ] 验证蓝牙断线重连、设备重启、电脑休眠唤醒、USB/BLE 切换、另一台电脑占用。
- [ ] 将应用放入“应用程序”后验证登录自动启动及关闭；不能只以注册调用成功代替重新登录验收。
- [ ] 检查隐私说明：本地读取记录，仅向设备发送状态、数量、用时、项目名及序号；不发送聊天正文，不需要 API Key。
