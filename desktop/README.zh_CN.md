# Codex Buddy 电脑端

AI Passport 的原生 macOS 菜单栏应用。支持 macOS 13 及以上，包含 Apple Silicon 和 Intel 两种架构，不需要 Python。Windows/Linux 暂不支持。

## 使用

1. 解压后将 `Codex Buddy.app` 放入“应用程序”文件夹并双击打开。首次启动显示连接引导；“设置”中的“连接引导…”可随时重新打开。
2. 给 AI Passport 通电，打开本机 Codex。自动模式优先 USB，USB 不可用时寻找蓝牙设备。
3. 首次使用蓝牙时，允许系统蓝牙权限。无需到系统蓝牙列表配对；由应用内直接扫描并连接。
4. 多个设备同时出现时，在“设置”中的 USB/蓝牙设备列表选择目标。设备一次只能接收一台电脑的蓝牙连接。
5. 可选择仅 USB、仅蓝牙，暂停同步、重新连接，或启用“登录时自动启动”。登录启动默认关闭，建议先把应用放入“应用程序”文件夹，再开启。

不要同时运行旧 Python 桥接程序；应用会检测连接锁并显示占用状态。设备需运行支持 Codex Buddy v1 协议的固件，蓝牙功能需 0.4.7 或兼容版本。

复制 `build/Codex-Buddy-macOS.zip` 到另一台 Mac，解压后即可使用；那台电脑也需要运行 Codex。本构建使用本地临时签名，没有 Apple Developer ID 签名或公证；其他 Mac 可能需要在系统安全设置中允许打开。

菜单首页仅保留互动、暂停同步、设置、帮助和退出。连接方式、设备选择、重新连接、连接引导、Codex 目录和登录启动统一放在“设置”中。

## 互动（0.2.0）

点击菜单顶部的小脸或“陪 Buddy 玩…”，打开互动面板。眼睛会跟随鼠标并自然眨眼，点击眼睛就是摸摸头，连续点会有不同回应。支持打招呼、夸奖、好奇、打盹，以及三组随机小剧场。

已连接时，设备使用现有表情及对应音效；未连接时只在电脑预览，不会把互动积压到重连之后。互动持续约 3–8 秒，也可以点击“回到任务”立即结束。新任务、任务完成、等待回复/审批、错误、暂停或连接改变会取消互动，面板始终单独显示真实任务。普通工具切换不会提前打断小剧场。声音仍由设备当前音量设置决定；本版本没有新增设备音频资源。

## 读取与发送范围

默认在本机读取 `~/.codex/sessions` 最近两天的任务记录。支持从启动环境读取绝对路径 `CODEX_HOME`；从 Finder 启动通常不会继承终端环境，因此自定义用户应在连接引导中选择目录。手动选择优先于环境变量，可选 Codex 数据目录或其 `sessions` 子目录，设置会保存在本机；“恢复自动检测”清除手动设置。向设备发送状态、进行中任务数、用时、项目目录名称与通信序号；默认不发送提问、回答、文件内容或工具输出。主动开启文字互动与字幕后，当前输入的字幕图像也会发送到设备，具体范围见下文。非 ASCII 或过长的项目名显示为 `Codex task`。

连接状态必须收到匹配序号的设备回执后才显示“已连接”。断开后自动重试，USB 恢复后优先切回 USB；设备被另一条 USB 连接占用时显示占用提示。

本机诊断摘要：`~/Library/Application Support/CodexBuddy/status.json`。只包含连接状态、状态名称、任务数量和 USB 端口，不包含聊天内容。

## 目录与构建

- `Sources/Interaction.swift`：短时互动序列、摸头回应与任务优先规则。
- `Sources/PetPanel.swift`：互动面板、鼠标跟随、眨眼与平滑眼形过渡。
- `Sources/main.swift`：菜单栏界面、偏好、连接切换、登录启动。
- `Sources/Transport.swift`：原生 USB 串口与 CoreBluetooth BLE。
- `Sources/StateMonitor.swift`：任务记录识别、协议编码与回执解析。
- `tests/StateMonitorTests.swift`：任务识别与协议边界测试。
- `scripts/build.sh`：构建、生成图标、本地签名和打包。
- `scripts/test.sh`：运行测试。

安装 Xcode 命令行工具后，在项目根目录运行：

```sh
desktop/scripts/test.sh
desktop/scripts/build.sh
```

构建产物位于 `desktop/build/`。可用 `MACOS_SDK_PATH` 指定 SDK；默认优先本机现有的 macOS 26.5 SDK，再使用系统默认 SDK。登录启动通过 Apple `SMAppService` 实现，是否允许运行由系统设置决定。

## 连接引导（0.3.0）

- 分开显示 Codex 来源检测与设备连接；目录不存在、无法读取、近期无记录各有提示。
- 可选择包含 `sessions` 的 Codex 数据目录，或直接选择 `sessions`。无效选择保留原设置；切换后清除旧任务缓存。
- 蓝牙列表可选择并记住设备。选择标识不等于安全配对或独占绑定；设备仍一次只接受一台电脑连接。
- 来源有近期记录且设备回执确认后，可点击“完成并在后台运行”。“稍后设置”不记为完成，下次打开继续引导。
- 不会自动开启登录启动；用户可在引导中主动勾选。建议先放入“应用程序”文件夹，系统如要求批准会给出提示。
- 近期记录存在只代表发现文件，不代表每个 Codex 版本的记录格式已兼容。请实际发起任务确认状态变化。

发布准备与待验收事项见 [RELEASE.zh_CN.md](RELEASE.zh_CN.md)。

## 文字互动与实时字幕（0.4.1）

0.4.6 字幕改用 17 像素苹方中等字重，以灰度覆盖率选择单色像素，关闭 LCD 子像素平滑；固定字体基线，避免追加标点或表情时上下移动。长句按完整字符裁切，前置省略号并保留末尾。固件 0.4.14 将底部简化为安静的两行：左侧为 16 像素弱化状态，右侧仅在任务进行时显示用时；第二行专供字幕，无字幕时留空，音量、详情和演示模式保留操作提示。移除色点、任务数量、分隔线和日常说明。两行使用 24 像素边距，字幕从 y=289 开始，底边留白 13 像素；432 字节单色协议不变，旧固件仍能接收新版字形。编辑至少稳定 300 毫秒后发布；按 500 毫秒采样节奏，持续输入时约每 1–1.5 秒更新。选中文字暂时保留上一条字幕，单独移动光标不发布旧内容，最后编辑约 5 秒后清空。这里采用快照合并，不能保证识别所有输入法的组词阶段，实际效果取决于输入框的辅助功能支持。

在“设置 → 文字互动与字幕”中主动开启，并在系统“隐私与安全性 → 辅助功能”里允许 Codex Buddy。默认关闭，可随时关闭。字幕需要固件 0.4.8；旧固件仍可同步任务与表情。

每 0.5 秒读取支持的当前输入框光标前最多 64 个 UTF-16 单元。切换输入框先建立基线，不立即展示原有文字；后续编辑在设备底部显示最新一行，长句显示末尾，停笔约 5 秒淡出。眼睛、任务状态与电量保留；音量、详情、动画预览优先于字幕。Mac 绘制 192×18 单色小图，经 USB/蓝牙发送，中文无需扩充设备字库。

“哈哈 / 加油 / 搞定”触发开心，“好困 / 晚安”触发打盹，“？？ / 为什么”触发好奇，“你好 / hi buddy”触发招呼。反应至少间隔 12 秒，等待确认、错误和正在播放的互动优先。文字与图像只在内存中处理，不写诊断、不发往云端；字幕图像会发送到你的设备。密码框和系统安全输入期间跳过。暂停、断开、关闭或权限失效时停止读取并清空本机缓存，设备字幕也会超时消失。

仅支持提供辅助功能文本范围的编辑控件。终端、自绘编辑器、部分网页可能无法读取；未上屏的中文候选文字不保证同步。蓝牙速度取决于协商传输大小与连接质量，0.5 秒是轮询间隔，并非端到端延迟保证。

### 字幕权限排查（0.4.2）

若本地更新电脑助手后任务同步正常、字幕消失，系统可能仍显示旧辅助功能条目开启，但新进程未获信任。在系统权限列表里将 Codex Buddy 关闭再开启，并按提示重启助手。使用本地临时签名时，修改可执行文件后可能需要重新确认。诊断只增加 `textEnabled`、`textPermission`、`textInputStatus`、`captionReady`，不记录文字或字幕图像。`permissionRequired` 表示卡在权限检查，不代表设备故障。

## 跟随系统外观

0.4.3 自动跟随 macOS 深浅主题，通过 USB 和蓝牙同步；设备需更新到 0.4.9 才支持浅色。无需新增权限或菜单，暂停同步时在恢复后应用当前主题。

### 更新后保留字幕权限

未配置固定证书时，本地构建使用临时签名，系统识别身份与该次可执行文件绑定。因此重新构建后，权限列表可能仍显示开启，但新版进程实际未被授权。只刷新 macOS“隐私与安全 → 辅助功能”（部分版本名为“设备控制和数据访问”）里的 Codex Buddy 条目；若开关无效，移除该条目后添加实际运行的应用，再重启助手。系统可能要求身份验证。建议只保留一个固定安装位置的应用副本。不要重置其他应用或编辑隐私数据库。

正式发布需保持 `com.johnny.codexbuddy` 标识和一致的 Developer ID 签名身份。运行 `scripts/build.sh` 时通过 `BUDDY_SIGN_IDENTITY` 指定证书名称或 SHA-1 身份；指定身份不可用会在替换应用前失败，不会退回临时签名。第一次从临时签名切换到证书签名仍需授权。支持证书签名不等于当前构建已公证，升级后的权限继承仍需实测。参见 [Apple TN3127](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。

### 本机免费固定签名

本机可使用长期自签名代码签名证书。私钥仅保存在登录钥匙串；`desktop/.signing-identity` 是忽略版本控制的本机证书 SHA-1，不包含私钥。构建默认读取它，证书不可用则停止；不要每次更新重新创建证书。指定 `BUDDY_SIGN_IDENTITY` 可覆盖默认身份。

本机自签名使用证书指纹与 `com.johnny.codexbuddy` 共同约束应用身份，不请求 Apple 时间戳；不会关闭 Gatekeeper。首次从临时签名切换仍需重新授权。后续更新保留同一证书、应用标识和安装位置，并实测字幕权限。该方式用于本机开发，不提供 Developer ID 或 Apple 公证的公开分发能力。更换 Mac 或丢失证书私钥后不能重建相同签名身份，需重新配置并授权。

2026-10-27 本机完成 0.4.4 → 0.4.5 覆盖更新测试：两版可执行文件 SHA-256 不同，签名指定要求一致；首次切换证书后恢复授权，第二版更新未操作权限，运行诊断 `textPermission=true`、USB 已确认连接。用户随后在日常输入位置实测，确认设备字幕正常显示。

## 空闲屏幕保护（助手 0.4.7 / 固件 0.4.15）

“设置 → 空闲自动熄屏”可选 1、3、5（默认）、10、30 分钟或永不熄屏。助手记住选项，通过 USB 和蓝牙发送 `screenOffSeconds`；固件仅在值变化时写入 NVS。字段缺失或无效时保留设备设置，兼容旧助手。协议接受 0（永不）或 60–3600 秒。

空闲 90 秒后背光降至 15%，动画从约每秒 30 次降至 5 次；达到设置时间后关闭背光并停止应用画面更新。通信监听继续运行，这是屏幕节能，不是芯片深度睡眠。任务执行、审批/等待/错误状态和表情演示期间保持亮屏。新任务或状态、新字幕、恢复连接、设备按键可唤醒；首次按键只唤醒。重复心跳不会重置计时，断开连接也会超时熄屏。修改熄屏设置会唤醒屏幕并重新计时。

构建和短时间设备检查不代表已通过全天候稳定性、面板寿命或实际功耗测量。

双击设备 OK 键可手动熄屏；按任意功能键唤醒，唤醒手势不会触发原有操作。手动锁屏期间，任务、字幕、连接变化均不会自动点亮，USB/蓝牙监听继续运行。亮屏时原有单击、长按功能不变，独立电源键保留原有开关机功能。
